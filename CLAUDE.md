# Écrin des Nuages

Site statique HTML, CSS et JavaScript natifs. Le catalogue, la galerie, les études et la sélection sont organisés en modules dans `features/`.

Tous les contenus et visuels publiés proviennent des ressources fournies pour Écrin des Nuages. Les fiches produit n’ajoutent pas de prix ni de détails non confirmés. Les CV et téléphones extraits des documents sources restent exclus du dépôt.

Le code du site a été créé avec Luna.
